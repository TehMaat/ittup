# Security policy

## Supported versions

Only the latest release gets security fixes. Pre-releases (`rc`, `.dev`) are for testing.

## Reporting a vulnerability

**Never open a public issue for a vulnerability.** Report it privately with a
[GitHub security advisory](https://github.com/TehMaat/ittup/security/advisories/new).

Include the affected version, how to reproduce it and the impact. Don't include real API keys, passkeys or
tracker URLs: replace them with placeholders.

You get a first answer within 5 working days. A confirmed vulnerability is a P0 (`sev:blocker`): it is fixed
in a patch release, then the advisory is published, crediting you if you wish.
